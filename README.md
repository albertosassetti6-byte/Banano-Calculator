# 🍌 Banano Calculator

Calcolatore responsive per stimare i guadagni in **BAN** da Folding@home.  
Prezzo live da CoinGecko, grafico a 7 giorni, sezioni About e Contact.

## ✨ Features
- Design responsive (desktop/mobile)
- Prezzo BAN in tempo reale (CoinGecko API)
- Grafico interattivo (Chart.js)
- Calcolatore PPD → BAN (giorno/settimana/mese)
- Data e ora in alto
- Link esterni a BananoMiner, Reddit, FaucetPay
- Crediti con icone HTML, CSS, JS, Chart.js, Font Awesome

## 📁 File
- `index.html`
- `style.css`
- `script.js`

## 🚀 Uso su CodePen
1. Incolla `index.html` nel pannello **HTML**
2. Incolla `style.css` nel pannello **CSS**
3. Incolla `script.js` nel pannello **JS**
4. Abilita i CDN esterni (Font Awesome, Chart.js, Google Fonts) — già inclusi nell'HTML
